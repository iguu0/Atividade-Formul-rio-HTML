# Atividade de Sala - Formulário de Cadastro

Este projeto foi desenvolvido como parte de uma atividade realizada em sala de aula, proposta pelo professor [Filipe H. S. Araujo](https://github.com/FilipeHSAraujo).

## Descrição

A aplicação consiste em um formulário de cadastro com validação de campos em HTML, CSS e JavaScript. O objetivo foi praticar a criação de interfaces e a lógica de validação para garantir que os dados informados pelo usuário estejam corretos antes do envio.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Campo de nome com validação mínima
- Validação de e-mail
- Verificação de senha com mínimo de 8 caracteres
- Confirmação da senha
- Mensagens de erro visuais
- Alerta de cadastro realizado com sucesso

## Como executar

1. Abra o arquivo `index.html` no navegador.
2. Preencha os campos do formulário.
3. Envie o cadastro e acompanhe as validações.

## Observação

Esta atividade foi um exercício prático de desenvolvimento front-end, realizado em ambiente acadêmico, com foco no aprendizado de validação de formulários e organização de código.
